Custom Markup Language Editor & Parser

Independent Software Developer

This project was born from a personal need for a tool that blends the simplicity of Markdown with the typesetting of LaTeX. I developed MyMD and its dedicated desktop editor.

Core features include an ANTLR-based compiler front-end and a JavaFX UI built on MVVM architecture. It uses the Visitor pattern to convert ASTs to Pandoc-compatible JSON, bridging the gap between casual writing and professional publishing.

Technologies: Java, JavaFX, ANTLR, MVVM, JUnit 5, Maven

Behavioural Modelling of Excessive Trading

Lead Developer / Quant Analyst

Quantitatively modelled the impact of psychological biases on excessive trading, sparked by market reactions to DeepSeek.

Architected a hybrid pipeline using Python (pandas) for data engineering and R (via rpy2) for PLS-SEM modelling. The study validated that Fear of Missing Out (FoMO) was the strongest predictive factor for irrational trading behavior.

Technologies: Python, R, PLS-SEM, rpy2, Matplotlib
